# Datacom Cyber Security Operations Job Simulation

This repository contains my completed work from the **Datacom Cyber Security Operations Job Simulation on Forage**, completed in August 2026.

The simulation provided experience analyzing a simulated cyber incident and evaluating cybersecurity risks across enterprise systems. I produced two security-focused deliverables documenting my findings, risk assessments, and recommended security controls.

## Project Overview

The simulation consisted of two cybersecurity tasks:

### 1. Security Breach Impact Analysis

I investigated a simulated ransomware incident affecting a healthcare organization.

The analysis included:

- Identifying the likely attack vector
- Reviewing indicators of compromise
- Evaluating compromised systems and data
- Assessing the operational and business impact of the incident
- Identifying weaknesses that contributed to the breach
- Recommending incident-response and security improvements

Indicators examined included a phishing-based initial compromise, suspicious login activity, credential theft using Mimikatz, and ransomware encryption affecting business-critical systems.

📄 [View Security Breach Impact Report](./Security-Breach-Impact-Report.pdf)

---

### 2. Cybersecurity Risk Assessment

I conducted a cybersecurity risk assessment for a simulated national retailer operating enterprise, cloud, e-commerce, and point-of-sale systems.

The assessment evaluated three major cybersecurity risks based on:

- Threat
- Vulnerability
- Likelihood
- Business impact
- Existing security controls
- Residual risk

I then developed mitigation recommendations involving areas such as:

- Multi-factor authentication
- Network segmentation
- Security monitoring
- Backup and recovery
- Phishing defenses
- Third-party risk management
